# ComandaLive

Proyecto integrador académico para coordinar pedidos entre clientes, meseros y cocina mediante una aplicación web.

## Estado del proyecto

Preparación del repositorio, definición del alcance y organización del trabajo del equipo.

## Alcance previsto

- Administración de usuarios, roles, menú y mesas.
- Solicitudes de pedido mediante QR por mesa.
- Revisión y confirmación del pedido por un mesero.
- Tablero de cocina y actualizaciones en tiempo real.
- Seguimiento de pedidos e historial de cambios.
- División de cuenta por platillos desde la vista del mesero.

Los pagos en línea y la facturación fiscal quedan fuera del alcance inicial.

## Tecnologías propuestas

- Backend: Python, Flask y Flask-SocketIO.
- Base de datos: PostgreSQL.
- Interfaz: Jinja, HTML, CSS, Bootstrap y JavaScript.
- Despliegue previsto: AWS EC2.
